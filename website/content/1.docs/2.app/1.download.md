# Download

Interfold is not currently published on the Google Play Store or the Apple App Store.

Native builds of the Android and iOS apps are published on
[GitHub Releases](https://github.com/Azyyyyyy/Interfold-app/releases)
(Android APK for sideloading, and an iOS IPA). You can also build any platform
(Android, iOS, desktop, or the experimental web app) from source — see the
[contributing guide](/docs/contributing/getting-started) and the repository README.

The Interfold website, including this documentation, is a rolling release: changes
on `main` go out as they land rather than waiting for an app version tag.

## Running an API instance

The app talks to an Interfold API that you (or someone else) host. There is no
central hosted API. The backend repository
[Azyyyyyy/Interfold](https://github.com/Azyyyyyy/Interfold)
includes a bootstrapper that is the fastest way to get a working instance up.

Point the app at that instance's URL when you first open it.

## Registering an account

To use the Interfold app, you will need to register an account using a third-party provider (currently Google, Apple, or Discord).
Interfold does **not** store any credentials like passwords; it exclusively uses these third-party services for authentication
for your security and privacy.

Please note that Interfold does not share any of your data with these third-party providers; they are only used for authentication purposes.
We also do not use any of the data from these providers except for your internal user ID.

If you previously registered an account using Discord, you can log in with that same Discord
account in the app to access your data. If you would like to link your Google/Apple account to your existing account,
you can do this by logging in with Discord **first** and then linking your other account in the app's settings.
