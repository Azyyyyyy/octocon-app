# Contributing to Interfold

Contributions to Interfold are welcome, whether that's code, design, or writing.
This guide will help you get started.

Interfold is a solo project maintained by [Azyyyyyy](https://github.com/Azyyyyyy).
The fastest way to get in contact is by opening an issue on
[GitHub](https://github.com/Azyyyyyy/Interfold-app/issues).

## GitHub

The Interfold project lives on GitHub under [Azyyyyyy](https://github.com/Azyyyyyy).
If you're new to GitHub, see the
[GitHub documentation](https://docs.github.com/en/get-started/start-your-journey/about-github-and-git).

The two main repositories are:

- [Azyyyyyy/Interfold](https://github.com/Azyyyyyy/Interfold): The Interfold API backend.
  Built as a .NET / C# service with
  [ASP.NET Core](https://learn.microsoft.com/aspnet/core), [ScyllaDB](https://www.scylladb.com/),
  and [PostgreSQL](https://www.postgresql.org/). Local development uses
  [.NET Aspire](https://learn.microsoft.com/dotnet/aspire/get-started/aspire-overview).
  The client talks to it over HTTP and Phoenix-compatible WebSockets.
- [Azyyyyyy/Interfold-app](https://github.com/Azyyyyyy/Interfold-app): The Interfold app
  (Android, iOS, desktop, and web) and the Interfold website and documentation
  (you're reading it right now!). The app is built with Kotlin and Compose
  Multiplatform using the Material 3 design system. The website lives in the `website/`
  directory and is built with Vue.js and Nuxt 3 with content written in Markdown.

## Reporting issues

If you find a bug or have a feature request, please open an issue in the appropriate repository. Please provide as much
detail as possible, preferably including steps to reproduce the issue and any relevant error messages or screenshots.

Additionally, if you're able to fix the issue yourself, pull requests are welcome. Please see the
[Contributing code](#contributing-code) section for more information.

## Contributing code

Interfold is a polyglot project. Web frontend (this site) is TypeScript with Vue.js and Nuxt 3.
The backend is C# / .NET (ASP.NET Core) with ScyllaDB and PostgreSQL.
The app is Kotlin with Compose Multiplatform using the Material 3 design system.
The app still uses Phoenix channel messages over WebSocket to receive realtime updates from the API.

For a local environment, native Linux, macOS, or WSL2 on Windows is recommended.

Suggested IDEs:
- Backend: Visual Studio, JetBrains Rider, or Visual Studio Code with the C# Dev Kit
- App: Android Studio (open the repository root Gradle project)
- Website: Visual Studio Code or WebStorm, with the `website/` directory as the project root

Git commit messages should follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification.
This allows us to automatically generate changelogs and version releases based on the commit history.
